# Доска

Бесконечная электронная доска для рисования, заметок и диаграмм на Electron:
чистый JavaScript и Canvas, без фреймворков и сборщиков.

![Интерфейс Доски](screenshot.png)

## Возможности

- **Рисование**: перо, маркер, заливка со собственным цветом, линия,
  стрелка, прямоугольник, круг, треугольник, объёмные фигуры, выделение
  и рука.
- **Три ручки** в нижней панели — чёрная, синяя и красная: отдельные
  инструменты с фиксированным цветом, толщину делят с пером, палитра
  «Цвет чернил» к ним не применяется. «Перо» в боковой панели осталось
  и рисует цветом палитры — как текст и фигуры.
- **Текст**: полужирный, курсив и подчёркивание (Ctrl+B/I/U), три
  гарнитуры и выравнивание по левому краю, центру и правому краю
  (Ctrl+L/E/R) — применяются к выделению, открытой правке или становятся
  умолчанием нового текста. Клик по написанному тексту открывает правку
  с содержимым, выделенным целиком.
- **Ластик** с круглой областью и слайдером 8–160 px в пикселях экрана:
  штрихи и контуры пустых фигур режутся по кругу касания, текст и залитые
  фигуры удаляются целиком, а картинки остаются — их вытирают только
  выделением.
- **Документ**: создание, открытие, сохранение, экспорт в PNG, история
  отмены и повтора, масштаб колесом, панорамирование, сетка и клетка.
- **Приборы**: линейка и транспортир.
- **Производительность**: доска перерисовывается только при реальном
  изменении — пустое движение мыши не запускает рисование, а координаты
  в статусе обновляются лишь при смене текста.
- **Полный экран**: вывод устойчив на современных видеокартах
  (Electron 44 с Chromium 152, флаги против мерцания проверены на RTX 5050).
- **Обновления**: «О программе Доска» в меню «Справка» показывает версию
  и проверяет, скачивает и устанавливает новые версии прямо с GitHub.

## Установка

Скачайте `Doka-Setup-3.3.1.exe` со страницы
[Releases](https://github.com/smold22/doka/releases) и запустите
установщик.

## Разработка

```bash
npm install   # зависимости
npm start     # запуск приложения
npm test      # 502 автотестов
npm run dist  # сборка установщика в dist/
```

## Технологии

Electron, чистый JavaScript, Canvas API.
