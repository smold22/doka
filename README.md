# Доска

Бесконечная электронная доска для рисования, заметок и диаграмм на Electron:
чистый JavaScript и Canvas, без фреймворков и сборщиков.

![Интерфейс Доски](screenshot.png)

## Возможности

- **Инструменты**: перо, маркер, заливка, текст, линия, стрелка,
  прямоугольник, круг, треугольник, объёмные фигуры, выделение, рука.
- **Ручки внизу**: чёрная, синяя и красная — три отдельных инструмента
  с фиксированным цветом и общей с пером толщиной; для них не показывается
  палитра «Цвет чернил». «Перо» в боковой панели осталось — оно рисует
  цветом палитры, как текст и фигуры.
- **Ластик** с круглой рабочей областью: слайдер размера 8–160 в пикселях
  экрана (не зависит от масштаба холста), штрихи и контуры пустых фигур
  режутся по кругу касания, текст и залитые фигуры удаляются целиком,
  а картинки остаются на месте — их вытирают только выделением.
- **Заливка** со собственным цветом, независимым от цвета пера.
- **Форматирование текста**: полужирный, курсив, подчёркивание (Ctrl+B/I/U),
  три гарнитуры и выравнивание по левому краю, центру и правому краю
  (Ctrl+L/E/R) — применяются к выделению, открытой правке или становятся
  умолчанием для нового текста.
- **Правка текста**: клик инструментом «Текст» или двойной клик по
  написанному тексту открывает его — содержимое выделено целиком, так что
  набор сразу переписывает старый текст.
- **Документ**: создание, открытие, сохранение, экспорт в PNG, история
  отмены и повтора, масштаб колесом, панорамирование, сетка и клетка.
- **Приборы**: линейка и транспортир.
- **Обновления**: «О программе Доска» в меню «Справка» показывает версию
  и проверяет, скачивает и устанавливает новые версии прямо с GitHub.

## Установка

Скачайте `Doka-Setup-3.3.0.exe` со страницы
[Releases](https://github.com/smold22/doka/releases) и запустите
установщик.

## Разработка

```bash
npm install   # зависимости
npm start     # запуск приложения
npm test      # 502 автотестов
npm run dist  # сборка установщика в dist/
```

## Технологии

Electron, чистый JavaScript, Canvas API.
