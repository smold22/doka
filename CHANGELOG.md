# Changelog

## 3.0.0 — 2026-10-03

### Ластик
- Курсор ластика — полупрозрачный круг по форме области стирания вместо крестика.
- Отдельный слайдер размера круга (8–80) с сохранением в настройках.
- Стирание режет штрихи и контуры пустых фигур по кругу касания: внутри круга
  контур исчезает, снаружи остаётся. Текст, картинки и залитые фигуры
  удаляются целиком при касании.
- В одном проходе размер круга только растёт: устранено дрожание размера
  при быстром движении с зажатой кнопкой.

### Заливка
- Собственный цвет заливки, независимый от цвета пера: палитра в режиме
  «Заливка» меняет только заливку, заголовок палитры переключается.
- Цвет заливки сохраняется в настройках и применяется к ведру и залитым
  фигурам; кнопка «Заливка» подсвечивается текущим цветом заливки.
